# Algorithms Practice

Репозиторий с реализациями классических алгоритмов и структур данных на Python.

## Two Pointers (два указателя)

**`two_pointers_sorted.py`** - поиск двух чисел с заданной суммой в отсортированном массиве.
- Время: O(n)
- Память: O(1)

**`two_sum_unsorted.py`** - поиск двух чисел с заданной суммой в неотсортированном массиве через хеш-таблицу.
- Время: O(n)
- Память: O(n)
